# Code of conduct

GitHub Profile Generator welcomes people with different backgrounds, experience, and levels of public activity. Participation should help make the project useful and respectful for everyone.

## Expected behavior

- Be considerate and respectful when discussing ideas, code, and people.
- Give feedback about the work, explain concerns clearly, and stay open to questions and different perspectives.
- Keep discussions relevant to the project and avoid sharing someone else's private information.
- Help make participation accessible; do not assume that a person's GitHub activity reflects their skill or experience.

## Unacceptable behavior

Harassment, insults, discrimination, threats, sexualized attention, deliberate disruption, and publishing private information without consent are not acceptable. This applies in repository discussions, issues, pull requests, and other spaces where someone is representing or discussing the project.

## Reporting and response

If you experience or witness behavior that violates this code, use a private contact method listed on the [maintainer's GitHub profile](https://github.com/juanNH). If none is listed, open a public issue that only asks for a private contact channel. Do not describe the incident, name anyone, or include sensitive details there. The maintainer will review reports as time allows and may remove content or limit participation when needed to keep the project spaces respectful. Reports will be handled discreetly to the extent practical.

This code applies to project spaces and to public conduct when someone is acting on behalf of the project. It is intended to guide participation, not to replace platform rules or legal processes.
