The animation lasts 9.8 seconds and is smaller than 500 KiB. The main README keeps it in a collapsible section, with static screenshots and written instructions available without opening it. It is a sequence of captured states, not a continuous recording or a simulated interface.

## Updating the screenshots

1. Start the application and open `/en/editor` in a browser or demonstration origin without personal data. Preserve any existing draft before replacing it.
2. Open the demo through **Project → Open project file**, review it and confirm.
3. Use a desktop viewport that shows both the editor and preview, the light theme and normal zoom. Hide the development indicator through its preferences without changing product code.
4. Capture the visible controls and result. For Project, keep the whole panel, including both download and open buttons. Crop only unnecessary margins or surrounding context; do not alter text or controls.
5. When updating the GIF, use states from the same workflow, consistent colors and transitions without flashes. Keep the static screenshots and inspect every frame before replacing the asset.
6. Check alternative text, relative paths, legibility and file sizes in the [root README](../../README.md).

Visible icons retain the attributions listed in [third-party notices](../../THIRD_PARTY_NOTICES.md). Assets are stored in the repository so relative links work across branches and copies of the project.
