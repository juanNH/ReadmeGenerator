# Documentation visuals

These assets show the current GitHub Profile Generator interface. They were captured in English on October 23, 2026, using the light theme and fictional data from the [demo project](../examples/demo-profile.project.json). They contain no credentials, real account data or activity queries.

| [readme-import-review.jpg](readme-import-review.jpg) | Detected Markdown sections and conversion notices before confirming an import.                 |

The main README uses static screenshots and written instructions so the product flow stays available without animation.

## Updating the screenshots

1. Start the application and open `/en/editor` in an isolated browser context with no personal data or saved draft. Load the [demo project](../examples/demo-profile.project.json) there.
2. Use a desktop viewport that shows both the editor and preview, the light theme and normal zoom. Hide the development overlay in the isolated capture context without changing product components or controls.
3. Capture the current editor, the project JSON import dialog and the README import review. For the import review, use fictional Markdown and stop before confirmation.
4. Keep images and activity cards inactive. Do not show credentials, real accounts or private data.
5. Crop only unnecessary margins or surrounding context; do not alter text or controls. Check alternative text, relative paths, legibility and file sizes in the [root README](../../README.md).

Visible icons retain the attributions listed in [third-party notices](../../THIRD_PARTY_NOTICES.md). Assets are stored in the repository so relative links work across branches and copies of the project.
